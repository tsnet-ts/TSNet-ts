# react-ts

Browser UI for transient hydraulic network simulation. Part of the [TSNet-ts monorepo](../README.md).

**Live demo:** [tsnet-ts.github.io/TSNet-ts](https://tsnet-ts.github.io/TSNet-ts/)

```bash
# from repo root
bun install
bun run dev
```
